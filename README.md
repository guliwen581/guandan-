# 掼蛋经典 · Guandan

> 零依赖、纯前端的掼蛋（Guandan）实现 —— 含完整规则引擎、启发式 AI、同端口 WebSocket 联机、WebAudio 音效与浏览器原生**人声解说**，并以**竞技掼蛋规则**为基准。

[![frontend](https://img.shields.io/badge/前端-原生JS-3178c6)]() [![server](https://img.shields.io/badge/服务端-Node·零依赖-5fa04e)]() [![rules](https://img.shields.io/badge/规则-竞技掼蛋-e0962a)]()

## 运行（无需安装任何依赖）

```bash
node server/main.js
```

浏览器打开 **http://127.0.0.1:8100** 即玩（同端口托管页面与 WebSocket 联机）。单机：大厅「快速开始」；联机：「联机对战」创建/加入房间，空位由 AI 补。

## 功能特性

- 🃏 **完整规则引擎**：单/对/三/三带二/顺子/连对/钢板/炸弹(4–10)/同花顺/天王炸；逢人配、级牌、A 掉头顺。
- 🏆 **打级赛制**：双上+3/头三+2/头末+1，过 A 通关；进贡/还贡/抗贡；接风。
- 🤖 **启发式 AI**：整体看牌、结构保护，跟牌优先用孤张。
- 🌐 **同端口联机**：自研极简 RFC6455 WebSocket，服务器权威 + 视角旋转快照 + 多项安全加固。
- 🔊 **音效 + 人声解说**：WebAudio 合成音效 + 浏览器原生中文 TTS 解说。
- 💬 **表情/快捷语**、🛒 **商业化外壳**（商城/月卡/首充/免费福利、钻石、VIP、记牌器）、🎨 **时尚 UI**。
